{# base.html — the frame that every page sits inside. Instead of copy-pasting the nav bar into six different files (and then editing it in six places every time you change it), you write it ONCE here. Every other page says "I'm based on base.html" and just fills in the middle. The magic word is {% block %}. It means "a hole that other pages fill in." Jinja2 gives you three things to remember: {{ something }} print a value {% if x %} ... {% endif %} do something conditionally {% for item in items %} ... {% endfor %} loop That's honestly most of it. ⚠️ ONE WEIRD TRAP — and I walked straight into it building this file for you, twice. Notice these notes are wrapped in a Jinja comment (the curly-brace-hash kind you see at the top and bottom of this block) instead of a normal HTML comment. That's on purpose. An HTML comment hides text from the BROWSER. But Jinja reads your file BEFORE the browser ever sees it. So if you put an if-tag or a for-tag inside an HTML comment, Jinja still tries to run it, and your whole page dies with a confusing "unknown tag" error. A Jinja comment hides things from Jinja too. Use it any time your note talks about Jinja code. And the second trap, which got me right after the first one: don't type the closing marker in the MIDDLE of a comment either. Jinja sees it and ends the comment early, and everything after it becomes live code again. Same lesson as forgetting a closing quote in Python. (Bonus: Jinja comments don't appear in the page source, so nobody can read your notes by hitting Ctrl+U.) #} {% block title %}Lost & Found{% endblock %}
