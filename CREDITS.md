# Credits

Open-source libraries used in this project. The Challenge rules allow these,
as long as you document them — which is what this file is for.

| Library | What it does for me | License |
|---|---|---|
| [FastAPI](https://fastapi.tiangolo.com/) | Turns my Python functions into web pages | MIT |
| [Uvicorn](https://www.uvicorn.org/) | The server that actually runs the site | BSD-3 |
| [Jinja2](https://jinja.palletsprojects.com/) | Puts my Python data into HTML pages | BSD-3 |
| [python-multipart](https://github.com/Kludex/python-multipart) | Handles form and file uploads | Apache-2.0 |
| [Pillow](https://python-pillow.org/) | Resizes uploaded photos | MIT-CMU |
| [pytest](https://pytest.org/) | Runs my tests | MIT |
| SQLite | Stores my data (built into Python) | Public domain |

Everything else — the matching engine, the database code, the routes, and the
HTML templates — I wrote myself. See `AI_USAGE.md` for where I got help.
